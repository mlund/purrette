# Contributing

Contributions of code, tests, documentation and bug reports are welcome.

- Keep changes focused: one logical change per pull request.
- Discuss large changes in an issue first.
- By contributing, you agree to license your work under MIT or Apache-2.0, at the user's option.
- If you adapt code from another project, say so in the file and keep its license notice.
- LLM coding tools are fine; you are responsible for what you submit. Agents follow [`AGENTS.md`](AGENTS.md).

Before opening a pull request, run the checks listed under "Before committing" in [`AGENTS.md`](AGENTS.md).
